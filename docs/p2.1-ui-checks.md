# P2.1 UI checks

Checked against the production-built control panel in a localhost harness with
synthetic IPC. No camera, microphone, or actual recording was started. The
screenshot is labelled Synthetic UI fixture and its numbers are not measurements
of a physical device. Live Electron integration remains a manual check.

## Direction and choices

User selected antislop during implementation and the existing light green/system
font style. Reading this as a tracking/debug tool for developers checking local
capture, with ENERGY 1 / RHYTHM 1 / MOTION 1. Tracking controls lead; timing, score
bars, and scripted-session controls follow the work sequence. System fonts require
no downloads, green is reserved for active controls, section spacing separates
measurement tasks, and bars show the requested live features without animation.
