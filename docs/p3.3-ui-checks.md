# P3.3 UI checks

2026-10-16. Direction: existing light green, system font, stationary targets.
ENERGY 1 / RHYTHM 1 / MOTION 1. Uniform tile sizes serve dwell selection; no decorative assets.

Checks used an isolated localhost preview with the actual InputController, React components
and stylesheet, fake native input, scripted text and in-memory settings. No real camera,
microphone, clipboard, destination writes or persisted user preferences were used.

## Delivery gate

- Hard gate PASS: no new marketing claims, testimonials, external assets, remote links or em dashes in UI copy.
- Layout PASS: rendered 1280x720 and 320x640; DOM measurements showed no horizontal overflow and no targets smaller than 64x64.
- Narrow layout PASS: 320px composer tiles measured 93x64; dock tiles 66x64. Footer and navigation no longer overlap.
- Contrast PASS: existing dark text #17211d on #f4f6f3, disabled #526057 on #e3e7e2, dark green pause control with white text; visible focus outline retained.
- Behavior PASS: browser keyboard activation opened palette, paged to saved phrases, composed and saved A, and opened the bilingual proposal. Fresh preview tab had no console errors.
- Confirmation PASS: proposal shows exact review text and mouth countdown; no confirmation button exists. Unit tests reject click confirmation and stale/unpresented voice evidence.
- Registry PASS: tests exercise every palette key, edit command, Excel starter and character action; configuration, cancel, paging and command dispatch have state tests.
- Keyboard PASS: overlay stays unfocusable to preserve destination focus; the control window mirrors palette actions with keyboard buttons and Escape close. Dwell remains available through main-side hit testing.
- States PASS: mic-off/gaze-only, empty draft, disabled actions, pending text, expiry, destination change, save failure message, busy insertion and overlay-loss pause are explicit states.
- Purpose PASS: fixed geometry supports dwell; green denotes active dwell; bordered text proposal separates the reviewed text from the destination. No gradients, glow, custom illustration or added font.
- Liveliness PASS: the proposal and progress indicator are the focal point; repeated stationary targets and restrained green feedback preserve Gestura's existing interaction identity.
- Craftsmanship PASS: strict CSP remains; build and full verification pass. No live hardware accuracy, Windows execution, or native-editor undo claims are inferred from this preview.
