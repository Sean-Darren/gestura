## Evidence and scope

Development renderer tested under its actual nonce CSP with a scripted local bridge using the real SpeechController. “Scripted UI preview” text is visibly labelled; this bridge does not open the microphone or run recognition. Real recognition was checked separately using upstream WAVs in Node and a windowless production Electron utility. The real AudioCapture/AudioWorklet was also exercised using an oscillator-backed MediaStream substituted for getUserMedia in a temporary test page; it did not access a microphone.

- Start/stop via mouse and Enter worked. Stop cleared the preview. Global pause stopped listening; Start became disabled with “Resume input before starting listening.” Resume does not automatically restart speech.
- Desktop button measured 134.75x52 CSS px with system-ui/sans-serif. Foreground rgb(244,246,243) against rgb(36,86,61) exceeds WCAG AA. At 375x812, button 136.22x52 px and no horizontal overflow. Temporary viewport override reset afterward.
- Overlay “Microphone live”: white on rgb(23,33,29), white edge, no animation, pointer-events none. Enter activation of the pause control removed the indicator. Ordinary pointer clicks pass through the overlay as intended; actual native corner dwell/hotkey remains a human OS check.
- Synthetic real worklet: 32 packets; each 512 samples; seq 0..31; 992 ms between first/last capture stamp (32 ms spacing), generated-tone RMS about 0.1416. Stream released, live false at completion. No captured warning/error logs in that test or the overlay.
- Production build passed. CSP stayed strict; shared Zod initialization disables generated functions in preload and the speech renderer. The temporary scripted bridge initially initialized Zod too late, causing a CSP error; that test adapter was corrected before the final UI checks.
